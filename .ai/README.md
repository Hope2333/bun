# .ai — AI-LTC Framework

This directory contains the AI Lifecycle & Task Coordination (LTC) framework
for the android-termux branch of Bun.

Purpose: Track planning, execution, and verification of Termux/Android
compatibility patches for Bun.

## Files

| File | Purpose |
|------|---------|
| `README.md` | This file — framework overview |
| `work-plan.md` | Task breakdown, progress, blockers |

## Principles

1. **Minimal patches**: Only change what's needed for Termux compatibility
2. **Upstreamable**: Each patch should be clean enough for upstream PR
3. **Verifiable**: Every change must be testable on Termux
4. **Tracked**: All work items have clear completion criteria
