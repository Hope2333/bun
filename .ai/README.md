# .ai — AI-LTC Framework

This directory follows the [AI-LTC](https://github.com/Hope2333/AI-LTC) framework
for long-horizon AI collaboration on the android-termux Bun branch.

## Structure
```
.ai/
  README.md                This file
  state.json               Current runtime state (SSOT)
  active-lane/
    current-status.md      What is happening now
    roadmap.md             Phase breakdown
  system/
    init-status.md         Integration checklist
```

## Quick Start for AI Operators

Read `active-lane/current-status.md` first, then check `state.json`.
